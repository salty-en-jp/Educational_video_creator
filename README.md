# 動画学習プロトタイプ(LAN内サーバー版)

自宅PC(Windows)をサーバーにして、同じ家庭内LANの端末から動画を視聴できる
プロトタイプです。「動画を見ずに修了扱いになること」をサーバー側で防ぎます。

## 仕組みの要点
- 動画は Range 配信(シーク・部分読込に対応)
- 再生中、ブラウザが5秒ごとに「いまの再生位置」をサーバーに送信(ハートビート)
- サーバーが**連続再生かどうかを検証**し、妥当な区間だけを「視聴済み」に記録
  - シークで飛ばした区間 → 視聴済みにならない
  - 極端な早送り(2.5倍超) → カウントしない
  - 離席(30秒以上ハートビートが途切れる) → カウントしない
- 視聴済み区間が90%を超えたら「修了」
- 判定はすべてサーバー側。ブラウザの「見終わった」という自己申告は信用しない

## セットアップ(Windows)

### 1. Python を用意
Python 3.10 以上をインストール(https://www.python.org/)。
インストール時に「Add Python to PATH」にチェック。

### 2. 必要なライブラリをインストール
このフォルダで「コマンドプロンプト」または「PowerShell」を開いて:

    pip install -r requirements.txt

### 3. 動画を置く
`videos` フォルダに mp4 を置き、`videos.json` を編集して登録します。
`duration` は動画の長さ(秒)です。例:

    [
      { "id": "lesson01", "title": "レッスン1", "file": "lesson01.mp4", "duration": 600 }
    ]

※ duration は正確に入れてください(修了判定の分母になります)。
   mp4の長さは、動画を右クリック→プロパティ→詳細、などで確認できます。
   サンプルで入っているlesson01,02は本当に適当に作った動画です。

### 4. サーバーを起動
LAN内の他端末からも見られるよう、host を 0.0.0.0 にします:

    uvicorn main:app --host 0.0.0.0 --port 8000

### 5. アクセス
- サーバーにしたPC自身から: http://localhost:8000
- 同じWi-Fi/LANの他端末から: http://（このPCのローカルIP）:8000
  - ローカルIPの確認: コマンドプロンプトで `ipconfig` を実行し、
    「IPv4 アドレス」(例 192.168.1.10)を見る
  - 例: http://192.168.1.10:8000

## つまずきやすい点
- **他端末から繋がらない**: Windows Defender ファイアウォールが
  Python/ポートをブロックしている可能性。初回起動時のダイアログで「許可」、
  または「ファイアウォールでアプリを許可」から Python を許可してください。
- **アクセスできなくなった**: PCのローカルIPが変わったのかも。
  ルーター設定で、このPCのIPを固定(DHCP予約)すると安定します。
- **`localhost` ではなく `0.0.0.0` で起動**しないと、他端末から見えません。

## 調整できるパラメータ(main.py 冒頭)
- `SEGMENT_SECONDS`   … 視聴管理の区切り幅(既定5秒)
- `MAX_SPEED_FACTOR`  … 許容する再生速度の上限(既定2.5倍)
- `COMPLETION_RATIO`  … 修了に必要な視聴割合(既定0.9 = 90%)
- `HEARTBEAT_MAX_GAP` … 離席とみなすハートビート間隔(既定30秒)

## このプロトタイプの限界(本番化の前に知っておくこと)
- 受講者IDはブラウザに保存した簡易ID。**本人確認はしていない**ので、
  本番では必ずログイン認証に置き換えること。
- LAN内限定は「アクセス範囲の限定」であって不正防止そのものではない。
- ハートビートは改ざんの余地が残る(本気の不正者はAPIを直接叩ける)。
  本番では、トークン署名・サーバー側の整合性チェック強化などが必要。

## クイズの編集

`quizzes.json` で、動画ごとにクイズを定義します。

    {
      "lesson01": [
        {
          "id": "l01q1",          // 一意なID(何でもよい)
          "at": 30,                // 何秒の地点で出すか
          "question": "問題文",
          "choices": ["選択肢A", "選択肢B", "選択肢C"],
          "answer": 1,             // 正解の番号(0始まり。この例だと選択肢B)
          "explanation": "正解時に出る解説"
        }
      ]
    }

- `answer` と `explanation` は**サーバー側だけが持ち**、フロントには送られません
  (ソースを見ても正解が分からない作りです)。
- 全画面モーダルで出題し、正解するまで動画は再開しません。
- 不正解の選択肢はその場で印が付き、選び直せます(ただしこれだけだと選択肢を
  総当たりされてしまうため、下記「不正解のときに巻き戻す」の `rewind_to` を
  設定することを推奨します)。
- 正解すると解説が出て「続ける」で再生に戻ります。
- 正解の記録は DB の `quiz_results` テーブルに残ります。

## 不正解のときに巻き戻す(基本的に設定を推奨)

クイズに `rewind_to`(秒)を足すと、**間違えたときにその位置まで動画を戻して**
見直させることができます。戻ったあと再びクイズ地点に来ると、もう一度出題されます。

**`rewind_to` は原則すべてのクイズに設定してください。** `rewind_to` を書かない
クイズは、不正解の選択肢にその場で印が付いて選び直せるだけの作りになっています。
選択肢を順番に押していけば内容を理解していなくても最終的には正解できてしまうため、
「動画をちゃんと見たか」を検証するという本来の目的を果たせません。`rewind_to` を
設定して該当箇所まで戻すことで、初めて見直し(=再学習)を強制でき、クイズが
意味のある確認として機能します。

    {
      "id": "l03q1",
      "at": 82,
      "question": "...",
      "choices": ["...", "...", "..."],
      "answer": 2,
      "rewind_to": 60,          // ← 間違えたら60秒地点まで戻す
      "explanation": "..."
    }

- `rewind_to` は必ず `at` より前の秒数にしてください
  (後ろだと戻した直後にまたクイズが出てしまいます。安全のため、
   `at` 以上の値が入っていたら巻き戻しは無効になります)。
- `rewind_to` を書かないクイズは、従来どおり「その場で選び直し」になります。

## ログイン機能

受講者を「ユーザー名+パスワード」で識別します。初回は登録画面で
「アカウントを新規作成」からユーザーを作り、以降はログインして使います。

設計の要点:
- 受講者の識別は**サーバーのログインセッション**で行います。視聴・クイズ・進捗の
  各APIは、ブラウザが送るIDではなくセッションから本人を特定するので、
  「他人のIDを送ってなりすます」ことができません。
- パスワードは平文では保存せず、ソルト付きの pbkdf2-sha256 でハッシュ化します。
- 未ログインのまま進捗APIを叩いても 401 で弾かれます。
- 進捗リセットは「ログイン中の本人の分」だけを消します。

本番化の前に知っておくこと:
- 今はHTTP(LAN)なので、パスワードは同じLAN内では平文で流れます。
  外部公開するなら **HTTPS必須**(その際はCookieに Secure も付ける)。
- 誰でも登録できる設定です。実運用では「管理者が発行」「登録コード制」などに
  変えるのが一般的です。
- ログイン試行回数の制限(総当たり対策)は入れていません。

## 管理者画面

管理者でログインすると、ヘッダーに「管理」ボタンが出ます。押すと
受講者 × 動画の一覧(視聴% と クイズ通過数)が表で見られます。

### 管理者の指定方法
`main.py` 冒頭の `ADMIN_USERNAMES` に、管理者にしたいユーザー名を書きます。

    ADMIN_USERNAMES = {"admin"}

複数指定する場合: `ADMIN_USERNAMES = {"admin", "tanaka"}`

**この名前のアカウントは `/api/register`(新規登録)からは作れません。** 誰でも
早い者勝ちで "admin" を名乗れてしまう問題を防ぐためです。代わりに、サーバー起動時に
自動で作成されます。

- 環境変数 `ADMIN_PASSWORD` を設定してから起動すると、そのパスワードで管理者アカウントが作られます。
- 設定しない場合はランダムなパスワードが自動生成され、**初回起動時に一度だけコンソールに表示されます**。
  現状パスワード変更機能はないので、必ずその場で控えてください。
- 一般の受講者が管理APIを叩いても 403 で弾かれます(画面にもボタンが出ません)。
- 一覧の各セルは「視聴% / クイズ通過数」。✓ は視聴が修了ライン
  (既定90%)に達した受講者です。

## コンテンツ管理(動画・クイズを画面から追加)

管理画面の「コンテンツ管理」タブから、JSONを手で編集せずに追加できます。

### 動画の追加
タイトルを入れて動画ファイルを選ぶだけです。**動画の長さは自動取得**されるので、
秒数を手で測る必要はありません。アップロードすると videos フォルダに保存され、
videos.json に自動登録されます。
- 「一覧から外す」を押すと受講者に表示されなくなります(動画ファイル自体は
  安全のため消さず videos フォルダに残ります。完全に消すときは手動で削除)。

### クイズの追加
動画を選び、出題位置(秒)・問題文・選択肢・正解(ラジオ)・解説を入れて追加します。
- 選択肢の空欄行は無視されるので、2〜4個の好きな数で作れます。
- **正解番号のズレ(以前ハマった answer の数え方)はもう起きません。**
  画面で正解の選択肢を直接選ぶ方式なので、番号を手で書く必要がないからです。
- 「不正解時の巻き戻し先」は入力欄としては任意ですが、**基本的には毎回設定することを推奨します**。
  空欄のままだと不正解時にその場で選び直せるだけになり、選択肢を総当たりされると
  見直しなしで正解できてしまうためです。

※ python-multipart が必要です。`pip install -r requirements.txt` で入ります。
